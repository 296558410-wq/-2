# V1 亏损法证 — 数据缺口与 UNKNOWN
## DATA_GAPS_AND_UNKNOWN

> 原则：市场数据不足 / 输入缺失 / 时间无法确认时一律标记 `UNKNOWN`，**禁止猜测**。
> 本节只列“影响本研究可得性”的缺口；均**不影响**当时决策事实（决策事实另见 `TRADE_ERROR_DATABASE.jsonl`）。

| `ticks_20260930` | 2026-09-30 20:54:59 → 22:05:00 | 70.0 min | 否 |

## 2. 决策期数据新鲜度 `data_age` = UNKNOWN（历史）

- 决策时守卫被喂 **`data_age_seconds = 0` 写死**（接线缺陷期）⇒ 账本未记录**当时真实的数据年龄**。
- 因此“这些亏损发生时数据是否陈旧”**无法**从历史记录判定 → **`UNKNOWN`**（不得反推）。
- 备注：该缺陷已随 `63d5a22`/`eceeec2` 修复，现网决策已携带真实 `data_age_seconds`。

## 3. 佣金 / 掉期口径缺口（历史 PNL 事件）

- 账本历史 `PNL` 事件只含**价差分量** `pnl`（无 `commission`/`swap` 字段）。
- 净额口径因此**只能**从券商 deal 另算（`profit + 开/平仓 commission + swap`）。
- 本报告两口径并列：价差 **−11.44** / 含成本净额 **−17.86**；**不混比同一限额**。

## 4. 时间帧标注（已知、非本分析错误）

- `broker_time_utc` / `live_state.last_bar_utc` 标记为 UTC，实为**服务器帧 UTC+3**（偏移 10800s）。
- 归档 tick `ts_utc` 标签同样为服务器帧；本分析已统一 **−3h** 换算（原始档 `m1_bars_snapshot.parquet` 保留服务器帧原样 + 记录哈希）。
