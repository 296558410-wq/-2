# V3 高频 Demo 交易与研究实验 001

冻结于 2026-10-05。授权依据：用户明确要求 V3 同时进行高频研究和 Demo 交易，并完成项目。

目标：tick 驱动、每秒计算的研究与交易闭环；独立记录真实策略成交、费用、净盈亏、延迟及前向预测。
本实验编号 `V3-DEMO-EXPERIMENT-20261005-001`，状态始终为 `EXPERIMENTAL_UNVALIDATED`，不是原 CAND-001 的正式 OOS 裁定，也不改写已冻结研究结论。

## 固定模型与信息边界

- 仅用已被查看的 2026-09-07 至 2026-09-21 开发数据。09-22 及以后原正式测试窗口不被训练、选择或评估脚本读取。
- 09-07..17 训练；09-18..21 为已经污染的开发诊断，绝不标成独立 OOS。
- 15 个 L1 特征，定义在 `demo_engine/features.py`；全部按过去和当前 tick 增量计算。tick-rule 仅称价格方向代理，缺失的 OFI、队列、冲击成本保持未知。
- 200-tick 特征保留最多 300 秒历史；实时预检发现当前报价频率约 2.6 tick/秒，原 60 秒缓存不足 201 tick，因此在发单授权前修正缓存容量并重新冻结全部模型。特征窗口、阈值和模型选择没有按盈亏调优。
- 标准化 Ridge，alpha=1，不搜索参数。5/10/30/60/300 秒全部输出，30 秒为预先固定的 Demo 交易周期。
- 训练与开发之间清除 300 秒；跨大于 5 秒行情断档的标签剔除。
- 置信余量来自训练集按时间块重采样的 95% 区间半宽；逆向选择项来自训练期方向残差估计。未建模冲击与成交不确定性明确保留，净优势可能偏乐观。
- 实验开始后模型文件哈希固定；研究服务观察全部周期，不能自动修改交易模型、阈值或正式测试协议。

## 交易规则与安全边界

- 当 30 秒预期方向毛优势减去当前点差、双边佣金、成本底线、逆向选择项与置信余量后大于 0，才产生 LONG/SHORT；否则 WAIT。
- 固定 V3 账户、服务器、隔离实例、XAUUSD、magic=90004；每次发单均验证真实 account.trade_mode 为 DEMO。
- comment 以 `V3S-` 开头；trade_source=`STRATEGY_SIGNAL_EXPERIMENTAL`，与历史 `CALIB-V3` 分开对账。
- 0.01 手，最多一仓；券商端保护止损，单笔风险预算最多 $1.50（包括佣金与滑点预留）。30 秒退出；风控/停机也允许退出。
- 每日上海日界亏损上限=min($5,日初权益1%)，最多30次开仓意图。三次连续拒单熔断。重复信号与未知结果不重发开仓。
- 开仓意图先持久化，再发送。未知订单结果锁住新开仓并按券商事实对账。重启从完整日志恢复，确认指定持仓后继续管理。
- kill/stop 文件只阻止开仓，仍保留平仓能力。程序错误、重启、停止时不能把已有仓位当成不存在。
- 查询失败不是空结果。真实净盈亏=sum(profit+commission+swap+fee)，点差和滑点已经包含在成交价中，不重复扣费。
- Broker 时间偏移由实测确认，本次 FXTM stamp=本机UTC+10800秒；原始时间、归一化时间与本机接收时间分别记录。

## 验收

离线：前缀特征不变、模型冻结、真实账户拒绝、重复意图阻止、拒单/未知结果恢复、重启持仓恢复、止损/超时退出、完整费用与账本、并发实例锁。

在线：独立 Demo 预检、持续新行情、真实信号评估、风控、订单回报、指定持仓退出、券商成交对账。没有正净预期时保持 WAIT；工程通过、实际成交、策略价值分别记录，不强行发单凑验收。

研究：持续记录未来才成熟的各周期 markout、模型误差、成本后效果及真实成交表现；按模型哈希分组，避免把不同版本合并。面板展示样本数、成交数、完整净盈亏及未知项。
