# Cross-cutting synthesis (what V3 should carry forward)

**1. **4. The two most portable *mechanisms* in Group A.**
- **Cost-multiple gate (A4), verified in code**: take a trade only if `StdDev ≥ 3 × roundTripCost` **and** `distanceToTarget ≥ 4 × roundTripCost`, where roundTripCost = spread + explicit commission input.
