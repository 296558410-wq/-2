## 2. X3 Beta Null Test

### 2.1 设计上的一个**退化**（必须先说）

预注册的 `NULL_UNCOND_LONG_SAME_TIMES`（在 X3 的同一批入场时刻无条件做多）**与 X3 本身完全相同** —— 因为 **X3 的方向恒为 +1**（`|z5|≥2 且 ch60>0 且 ret5>0` 触发后永远做多）。所以"同时刻无条件做多"捕获 X3 毛边的 **100%**，按预注册规则**退化地**触发 `BETA_EXPLAINED`。

**这个零假设对 long-only 信号是无效的。** 因此我另外补了三个**不同入场集**的对照（同一冻结协议内、未调 X3 规则）：

### 2.2 对照结果（MAIN，X3 入场 973 次，各期 gross bp）

| 基准 | 1m | 5m | 15m | 30m | **60m** |
|---|---|---|---|---|---|
| **X3（long-only）** | −0.212 | +0.294 | +1.280 | +2.495 | **+4.261** |
| 随机同数量做多（固定种子） | +0.174 | +0.633 | +0.311 | +1.046 | **+1.974** |
| 全部 bar 无条件做多 | +0.018 | +0.066 | +0.183 | +0.402 | **+0.914** |
| 分段买入持有（n=1,055） | 均值 **+0.592** / 中位 **−0.023** | | | | |

**差异（X3 − 对照）**
- 60m：X3 比**随机同数量做多**高 **+2.287 bp**；比**全 bar 做多**高 **+3.347 bp**
- 30m：比随机高 **+1.449 bp**；比全 bar 高 **+2.093 bp**

### 2.3 X3 判定：**`INCONCLUSIVE`**

| 项 | 读数 |
|---|---|
| 预注册规则 | `BETA_EXPLAINED`（**但因 X3 恒为多而退化，无信息量**） |
| 补充对照 | X3 **优于**随机做多与全 bar 做多 ⇒ **不只是"漂移"** |
| 但仍不可采信 | ① **long-only**，无法与 beta 分离；② 冻结阶梯判 `EXECUTION_UNREALISTIC`（`std 32.76bp > 5×|4.261|`）；③ 分段买入持有均值仅 +0.59bp 而中位 **−0.02bp**，说明"做多"本身在本样本并不稳定盈利 —— 这让 X3 的高毛边更像**少数极端样本**而非稳定暴露 |

**⇒ X3 不能判 alpha，也不能简单判 beta。结论：`INCONCLUSIVE`，需要 redesign（见 §4）。**

```
V3_R2 = NO_VALIDATED_EDGE_CONFIRMED
```

**下一步（有序）**
1. **P3 不再加码**：它在两份独立样本上都倒在 2× 成本，且 OOS 不稳。继续调参只会过拟合。
2. **X3 要 redesign 才能定性**：当前形式恒为多 ⇒ 必须改成**双侧**（把 `ch60>0 且 ret5>0` 换成对多空对称的状态条件），或直接改为**市场中性**（long X3 / short 同时刻随机）的价差检验。**在新协议下重跑**。
