- 产物：`DATA_GAP_AUDIT.json`｜脚本：`data_gap_audit.py`（只读）
- 边界：未改任何 PIT 定义、未放宽任何窗口、未删样本；未下单
- 方法说明：**本审计的第一版有 bug**——它把 `flags` 也算作「volume 类」字段，而 `flags` 是 100% 非零的位掩码（值 1026–1158），导致误报 `any_nonzero=True`。**已修正为逐列精确判定**，下面为修正后结果。

## C. Volume / OFI 可得性

| 快照 | 文件 | 列 | volume / volume_real / last | bid/ask size |
|---|---|---|---|---|
| MAIN `V3-SNAP-20260922T025312Z` | 36 | `time,bid,ask,last,volume,time_msc,flags,volume_real,utc_ms,ts_utc` | **全 0（0 / 7,285,000，0.0000%）** | **不存在** |
| PIT2 `V3-SNAP-PIT2-20261001T131500Z` | 9 | 同上 | **全 0（0 / 1,712,560，0.0000%）** | **不存在** |

样本行（两份快照一致）：
```
{'bid': 4422.18, 'ask': 4422.41, 'last': 0.0, 'volume': 0, 'volume_real': 0.0, 'flags': 1158}
{'bid': 4377.88, 'ask': 4378.11, 'last': 0.0, 'volume': 0, 'volume_real': 0.0, 'flags': 1030}
```

**判定：`TRUE_OFI_DATA_UNAVAILABLE`** ✅（与 R1 的判断一致）

- 模式里**有** `volume` / `volume_real` / `last` 三个字段，但**取值恒为 0**；**没有** bid/ask 挂单量或成交量字段。
- 后果：**一切"流量类"特征都只能是报价口径的 `_PROXY`**（用价格变动符号代替方向），**不是真实订单流**。
- 这不影响本审计的结论，但它**永久限制**了 F1 族（tick/微观结构）能够表达的东西：真正的 OFI、队列位置、成交流方向**在现有数据源上不可构造**。
- 要解除：需要换数据源（带 size/volume 的 tick 或 L2），**不是**换算法。

## D. Event × Tick 对齐审计

| 阶段 | 计数 | 损失 |
|---|---|---|
| 原始事件行（vintage `JIN10_CALENDAR_20261001T130733Z.json`） | **283** | — |
| PIT 合格（有 `pub_time`） | **283** | 0 |
| 落在 PIT2 tick 窗口内 | **223** | **−60** |
| 有完整前 60s + 后 15min 窗口 | **223** | 0 |
| **独立时间戳（全局 / 窗口内）** | **75 / 57** | 见下 |

**损失原因（逐条）**

1. **60 行落在 tick 窗口之外**：vintage 覆盖 **2026-09-28 → 10-03**，而 PIT2 快照止于 **2026-10-01 12:54Z** ⇒ 10-02 的 27 行与 10-03 的 7 行**根本没有 tick**（其余零散）。
2. **208 行被 R1 loader 的去重合并 —— 这是我的实现缺陷**：事件在**同一分钟并发发布**（美盘数据集中释放），共 **52 个并发组**；R1 的加载器用 `set((ts, 文件名))` 去重，把**同一时刻的多条事件折叠成 1 条**。
   ⇒ R1 实际喂进模型的只有 **75 个独立时间戳**（窗口内 57）；E1/E2/E4 更少（38–50）。
3. **PIT 规则未改、窗口未放宽、样本未删** —— 本审计没有为了让数字变大而动过任何定义。

**可用率**
- **按行**：223 / 283 = **78.8%**
- **按独立时间戳（窗口内 / 全局）**：57 / 75 = **76.0%**
- R1 实际使用：**75**（全局去重数），其中窗口内 57

**结论**：F5（事件交互）在 R1 中**既欠功效、又被我少算**。真实可用量是 **223 行 / 57 个独立时刻**，而不是 R1 报告的 75。**若要把事件族做扎实，应在新的冻结协议下按"行"（而非按时间戳去重）重建样本**；同时把事件语料与 tick 窗口对齐（当前二者只重叠 4 天）。
