## 1. 数学审计（单位与尺度）

**定义（F-R1 冻结）**
```
zma = (close_t − SMA_20(close)_t) / ( close_t · σ_ret20_t · √20 )
```

**单位核对**
| 项 | 单位 |
|---|---|
| 分子 `close − SMA₂₀` | 价格 |
| 分母 `close` | 价格 |
| 分母 `σ_ret20` | 无量纲（收益率标准差） |
| 分母 `√20` | 无量纲 |
| ⇒ 比值 | **无量纲 ✓** |

**单位本来就对**。问题只在分母的**尺度**是否等于分子的标准差。

**正确尺度推导（随机游走）**
设每根 bar 的增量 iid、每 bar 价格方差 `s_p²`。令
`D_t = close_t − SMA_n = (1/n)·Σ_{k=1..n−1} (close_t − close_{t−k})`

则 `Cov(close_t−close_{t−k}, close_t−close_{t−l}) = min(k,l)·s_p²`，于是

```
Var(D) = [ Σ_{k,l=1..n−1} min(k,l) / n² ] · s_p²
       = [ (n−1)(2n−1) / (6n) ] · s_p²
⇒ std(D) = s_p · K_n ,   K_n = sqrt( (n−1)(2n−1)/(6n) )
```

`n = 20`：`Var` 因子 `= 19·39/(6·20) = 6.175`，`K₂₀ = 2.484955`。
而 F-R1 用的是 `sqrt(20) = 4.472136`。

```
比值 = 4.472136 / 2.484955 = 1.799685   ⇒ 分母宽了 80.0%
等价的阈值含义：|zma| ≥ 2  ⇔  真正规化下的 |z| ≥ 3.599
```

**理论触发率（纯高斯）**
- 正确标尺：`P(|z|≥2) = 4.550%`
- 冻结标尺：`P(|z| ≥ 3.599) = 0.0319%`

## 2. 三重独立验证

### ① 代数（上面的闭式解）
`K₂₀ = 2.484955`，误差比 `1.799685`，分母宽 80.0%。

### ② 合成数据（**不含任何市场数据**）
20 万根 iid 合成 bar：

| 合成 | n | std(frozen) | std(correct) | 比值 | 触发率 frozen@2 | 触发率 correct@2 |
|---|---|---|---|---|---|---|
| 高斯 iid | 199,979 | 0.5804 | **1.0445** | **0.5557** | 0.126% (251) | **5.619%** (11,236) |
| Student-t(4) | 199,979 | 0.5885 | **1.0591** | **0.5557** | 0.200% (400) | **5.735%** (11,469) |

- 修正后 std ≈ **1.04**（≈1 ✓ 标尺正确）；冻结版 std = **0.58**（远小于 1 ✗）
- 比值 `0.5557 = 1/1.799685`，**与代数预测逐位一致**

### ③ 实盘快照（**只做分布，不算收益**）
`V3-SNAP-20260922T025312Z` → 47,963 根 1m bar / 1,055 段：

| 项 | 值 |
|---|---|
| std(frozen) / std(correct) | 0.5706 / **1.0269** |
| **比值** | **0.5557**（与合成、与代数**完全相同**） |
| 触发 @\|z\|≥2 **冻结标尺** | **102 / 46,037 = 0.2216%** |
| 触发 @\|z\|≥2 **修正标尺** | **2,374 / 46,037 = 5.1567%** |
| 冻结版实测/理论 | 0.2216% / 0.0319% = **6.95×** |

> **可重复性核对**：冻结标尺在本审计中触发 **102** 个——与 F-R1 记录的 `raw=102` **完全一致** ✅

> **额外发现（值得写进 R2 的前置断言）**：实测尾部比高斯表**厚约 7 倍**（0.2216% vs 0.0319%）。原因是**滚动 σ 估计噪声 + 真实收益厚尾**。⇒ **任何触发率都必须实测标定，不能照抄正态表**。
