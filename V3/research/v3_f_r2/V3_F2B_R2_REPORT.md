## 12) 最终判定

```
STATUS = NO_VALIDATED_EDGE
```

**淘汰路径（逐条对照冻结判定标准）**

| 判定要求 | FADE 是否满足 |
|---|---|
| A1–A4 PASS | ✅ 满足 |
| 成本后仍有正向收益 | ❌ **不满足**——1× 成本后全期限为负（最好 30m −0.1761 bp） |
| OOS 支持 | ⚠️ 15m+ OOS 为正，但 IS 为负 ⇒ **IS/OOS 方向不稳定**，不构成支持 |
| permutation 支持 | ⚠️ 仅 5m p=0.016，但该期限毛边低于成本 |
| bootstrap CI 不否定 | ❌ **五个期限 CI 全部含 0** |
| effective_n 足够 | ✅ 全部 ≫30（389–1,786） |
| 不依赖单一时段/波动区间 | ❌ 仅 1m/5m 全桶同号；15m+ 出现反向桶 |
| FADE 方向有独立证据 | ⚠️ 方向本身一致（FADE 优于 CONT），但 CONT 是精确镜像 ⇒ 非独立证据 |

**结论**：**修正标尺后的均线反转假设，未构成可覆盖成本且可重复的 XAUUSD 短周期 edge。**

**与 F-R1 的差别（仅作对照，非继承结论）**：修正后触发率从 0.22% 升到 5.16%（23.3×），事件从 102 升到 2,374，`effective_n` 从 68 升到 1,786 —— **功效问题已彻底解决**。但结论**未改变**：毛边仍不足成本（最好 0.738 bp vs 成本 0.914 bp），且 bootstrap CI 全部跨 0、FDR 0/10。**这不是"样本不足"，是"成本墙"。**

**附：A4 与"特别禁止"清单核对**——未缩小/扩大触发阈值；未改持有期；未删除极端事件；未修改成本；未修改 IS/OOS 切分；未增加任何未预注册的筛选条件。任何额外探索均未混入本轮结果。
