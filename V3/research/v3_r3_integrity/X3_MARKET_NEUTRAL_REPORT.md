# V3 R3 · X3 市场中性重设计报告

- 协议：`V3_R3_FROZEN_PROTOCOL.json` 的 `W4_x3_market_neutral` 段；**计算前冻结**
- 样本：`UNION`（8,782,369 ticks / 43 个活跃交易日）
- 结论前置：**X3 的"边缘"在原形态下主要来自 long-only 的方向暴露；改成市场中性后，边缘消失。**
- 边界：未改任何阈值（`|z5|≥2`、σ20、5-bar 冲量、60-bar 制度窗口全部原样）｜**未挑选有利时段**｜**未删除亏损样本**｜**未用 R2 结果反向调整新定义**

---

## 1. 新定义（事前冻结）

```
X3MN_TWO_SIDED:
  触发   : |z5| >= 2.0                        （z5 = ret5 / (sigma20 * sqrt(5))，全部沿用）
  制度   : 60-bar 变动符号
  方向   : 制度 > 0 → LONG ；制度 < 0 → SHORT ；制度 = 0 → 不交易
  入场   : 触发 bar 收盘后的第一个 tick（多头吃 ask / 空头吃 bid）
  出场   : entry + h 的第一个 tick 的 mid
```
**与旧 X3 的唯一差别**：旧 X3 在 `制度>0 且 ret5>0` 时**只做多**；新定义**由制度决定多空**，因而是**双侧**的。

**零假设 / 对照**
- `MATCHED_EXPOSURE_BASELINE (MEB)`：对每个信号，在**同一分钟、同一星期几、不同周**（`+7 天`）取一个对照入场，**取相同方向**；`alpha_MEB = mean(信号) − mean(对照)`
- `BETA_CHECK`：**分别报告 LONG 腿与 SHORT 腿** —— 若空腿在其自身方向上也为负收益（即做空亏钱），则原效应很可能是**市场上行漂移**而非 alpha

## 4. 四条决定性读数

**① 市场中性后，"边缘"塌了**
旧 X3（long-only）60m gross **+4.261 bp** → 新 X3MN（双侧）60m gross **+0.7887 bp**。
⇒ **原 X3 约 81% 的毛边来自"只做多"这一件事本身。**

**② SHORT 腿在**每一个期限**上都是负的**
−0.135 / −0.603 / −0.178 / −0.022 / −0.989（60m 空腿净收益 **−1.903 bp**）。
⇒ 做空系统性亏钱，这正是**市场在该样本内整体上行**的特征。**方向性暴露 = beta，不是 alpha。**

**③ 成本后全期限为负**
净(1×)：−1.019 / −1.136 / −0.244 / −0.164 / **−0.125**（最好的一条 60m 仍为 −0.125 bp）。
⇒ **连 1× 都过不去**。

**④ 匹配暴露 alpha 不一致**
`alpha_MEB`：+0.014 / −0.322 / +0.324 / −0.175 / **−0.527** —— **符号来回翻**，没有任何一致的择时能力证据。

## 5. 时间稳定性

60m 的月度块：**2026-08 +1.6153（n=1370）／ 2026-09 −0.2132（n=1275）／ 2026-10 +4.2421（n=42）**
⇒ **9 月整体为负**，8 月为正 —— **方向按月翻转**，与 W1 中 P3 的"8 月强、9 月弱"是同一现象。再叠加 `TEMPORAL_EVIDENCE_INSUFFICIENT`（58.5 天 < 90 天）。

## 6. 判定

```
X3MN_VERDICT = COMPUTED（设计可构建，未 BLOCKED）
X3MN_EDGE    = NO_VALIDATED_EDGE —— 成本后全期限为负
X3 性质判定  = BETA_EXPLAINED（结构化解释，非退化规则）
```

**与 R2 的区别（重要）**：R2 的零假设（"同时刻无条件做多"）对 long-only 信号**退化、无信息量**；**本轮的证据不是退化规则，而是两个具体事实**：
1. **双侧后边缘塌掉 ~81%**；
2. **空腿在每个期限都亏**。

**⇒ 原 X3（`|z5|≥2 且 ch60>0 且 ret5>0` → 恒多）不应再作为 alpha 候选。** 它的表现是**该样本内上行漂移 × 多方向暴露**的产物。

**建议（不在本轮执行）**：若仍要检验"冲量×制度"这个机制，应把**方向由制度对称给出**（即本轮 X3MN 的形式），并在**≥90 天 / ≥40 交易日**的样本上、以**匹配暴露 alpha 一致性**为门槛重跑。本轮的结论是：**在当前样本上它没有可交易的 alpha。**
